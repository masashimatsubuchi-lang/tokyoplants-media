## 結論：基本は赤玉土5割

観葉植物の土における赤玉土の配合割合は、以下が目安です。

| 植物タイプ | 赤玉土の割合 | 配合例 |
|-----------|------------|--------|
| 一般的な観葉植物 | 50% | 赤玉土5：パーライト3：バーク堆肥2 |
| 乾燥を好む植物（サンスベリア等） | 40% | 赤玉土4：軽石3：パーライト2：くん炭1 |
| 湿り気を好む植物（シダ類等） | 50% | 赤玉土5：ピートモス3：バーミキュライト2 |
| 着生植物（モンステラ等） | 40〜50% | 赤玉土4：バーク堆肥3：パーライト3 |

<mark>多くの観葉植物は赤玉土5割で問題ありません。迷ったら5割から始めてください。</mark>

詳しい配合方法の基礎は[土の配合方法の完全ガイド](/soil/how-to-mix-soil-for-houseplants)も参考にしてください。

## 赤玉土5割の科学的な理由

「なんとなく5割」ではありません。赤玉土5割には、土壌科学と植物生理学に基づく根拠があります。

### 理由1：団粒構造が最大化する割合

赤玉土の粒は「マクロポア（大きな空隙）」と「ミクロポア（粒内部の細孔）」を持ちます。マクロポアは排水と通気を担い、ミクロポアは保水を担います。

赤玉土5割の配合では、この二重の空隙構造が十分に機能します。3割以下では空隙が少なくなりすぎ、7割以上では単位体積あたりの保水量が増えすぎて乾燥に時間がかかります。

### 理由2：根の活着に必要な保水量が確保できる

根は常に微量の水分と酸素を必要とします。赤玉土5割の配合では、水やり後に適量の水分が粒内部に保持されながら、余剰水は速やかに排出されます。これが「根の乾湿サイクル」を生み出し、根の健全な成長を促します。

### 理由3：弱酸性pHが多くの観葉植物の適正範囲に収まる

赤玉土のpHは5.5〜6.5の弱酸性です。モンステラ・フィロデンドロン・アロカシアなど、熱帯雨林由来の観葉植物の多くはpH6.0前後を好みます。赤玉土5割の配合は、他の素材と混合した際にこの適正pHを維持しやすいため、5割が基準として定着しています。

### 理由4：無機質ベースで清潔さを保てる

赤玉土は無機質素材です。全体の5割を無機質の赤玉土が占めることで、有機質素材（バーク堆肥・ピートモスなど）の割合が抑えられ、室内環境でもカビや害虫のリスクを低減できます。

## 赤玉土とは何か

赤玉土は関東ローム層から採取される火山灰土を粒状にしたものです。園芸用土の中で最も基本的な素材で、以下の特性を持ちます。

- **排水性と保水性のバランスが良い** — 粒の間を水が通り、粒自体が水を含む
- **通気性が高い** — 粒と粒の間に空気の層ができる
- **無機質** — 有機質を含まないため、虫やカビが湧きにくい
- **弱酸性（pH5.5〜6.5）** — 多くの観葉植物の適正pH範囲に近い
- **無肥料** — 肥料成分を含まないため、施肥で栄養をコントロールできる

赤玉土単体では保水性が高すぎるため、パーライトや軽石など排水性を高める素材と組み合わせて使います。[観葉植物におすすめの土の全体像を見る](/soil/recommended-soil-for-houseplants)

## 粒のサイズの選び方

赤玉土には小粒・中粒・大粒があり、用途が異なります。

| サイズ | 粒径 | 用途 |
|-------|------|------|
| 小粒 | 2〜5mm | 観葉植物の主体土（最も汎用性が高い） |
| 中粒 | 5〜10mm | 大型鉢の主体土、鉢底石の代用 |
| 大粒 | 10〜20mm | 鉢底石として使用 |

**観葉植物には小粒が基本です。** 根が細い植物は小粒でないと根が土に馴染みません。

大型の鉢（8号以上）の場合は中粒を使うと排水性が高まります。ただし中粒は保水性がやや低いため、保水素材の割合を少し増やしてバランスを取ります。

## 植物別の配合レシピ10種類

### 1. モンステラ（デリシオサ・アダンソニー等）

```
赤玉土（小粒）4 ：バーク堆肥 3 ：パーライト 3
```

着生植物のモンステラは根に空気が当たることを好みます。バーク堆肥の粗い粒が空気の通り道を作り、パーライトが排水性を確保します。[モンステラにおすすめの土を詳しく見る](/soil/best-soil-for-monstera)

### 2. アロカシア（ドラゴンスケール・ポリーなど）

```
赤玉土（小粒）4 ：軽石 3 ：パーライト 2 ：くん炭 1
```

アロカシアは根腐れしやすいため、軽石を多めに入れて排水性を高めます。くん炭で抗菌効果を加えると根腐れのリスクをさらに下げられます。

### 3. アンスリウム

```
赤玉土（小粒）3 ：バーク堆肥 4 ：パーライト 3
```

アンスリウムも着生性が強く、根が空気に触れやすい配合が理想です。バーク堆肥の割合を高めて、粗い粒感のある配合にします。

### 4. フィロデンドロン

```
赤玉土（小粒）4 ：バーク堆肥 3 ：パーライト 2 ：くん炭 1
```

フィロデンドロンは熱帯雨林の林床で育つため、腐植質を含む通気性の高い土が適しています。モンステラよりやや保水性を持たせた配合です。

### 5. パキラ

```
赤玉土（小粒）4 ：日向石 3 ：パーライト 2 ：くん炭 1
```

パキラは乾燥に強く過湿に弱いため、日向石で排水性を最大化します。[パキラの土選び詳細はこちら](/soil/best-soil-for-pachira)

### 6. ウンベラータ（フィカス）

```
赤玉土（小粒）5 ：パーライト 3 ：バーク堆肥 2
```

スタンダードな観葉植物配合がそのまま使えます。ウンベラータは比較的丈夫で、赤玉土5割の基本配合で問題ありません。

### 7. ポトス（エピプレムヌム）

```
赤玉土（小粒）5 ：パーライト 3 ：バーク堆肥 2
```

ウンベラータ同様、基本配合で十分です。ポトスは適応力が高いため、細かい配合にこだわらなくても育ちます。

### 8. サンスベリア（スネークプラント）

```
赤玉土（小粒）4 ：軽石 3 ：パーライト 2 ：くん炭 1
```

多肉質の根を持つサンスベリアは過湿に非常に弱いです。赤玉土4割に抑えて軽石を増やし、徹底的に排水性を高めます。冬はほぼ断水するため、乾きやすい配合が必須です。

### 9. ザミオクルカス（ZZプラント）

```
赤玉土（小粒）4 ：軽石 4 ：くん炭 2
```

ザミオクルカスは根に水分を蓄える地下茎（根茎）を持ち、乾燥に非常に強いです。軽石を多用して排水性を極限まで高めた配合にします。ピートモスや腐葉土は不要です。

### 10. シダ類（ボストンファーン・ネフロレピスなど）

```
赤玉土（小粒）5 ：ピートモス 3 ：バーミキュライト 2
```

シダ類は湿り気を好む植物です。ピートモスとバーミキュライトで保水性を高めますが、赤玉土5割を維持することで根腐れを防ぎます。ピートモスは酸性が強いため、石灰を少量加えてpH調整するとなお良いです。

## 赤玉土の割合を調整する判断基準

赤玉土の割合を増減する基準は、植物の根の特性と管理環境で決まります。

### 赤玉土を増やす（6割）場合

- 水やり頻度が高い（毎日〜2日に1回）
- 風通しの良い場所で管理している
- 素焼き鉢を使っている（蒸発が速い）

### 赤玉土を減らす（3〜4割）場合

- 水やり頻度が低い（週1回以下）
- エアコンの効いた部屋で管理している
- プラスチック鉢を使っている（蒸発が遅い）
- 多肉質の根を持つ植物

## 硬質赤玉土を選ぶべきか

赤玉土には通常品と硬質（焼成）品があります。

| 項目 | 通常の赤玉土 | 硬質赤玉土 |
|------|-----------|-----------|
| 価格 | 安い（5L 300〜500円） | 高い（5L 600〜1,000円） |
| 粒の持ち | 1〜2年で崩れる | 2〜3年持つ |
| 排水性の持続 | 短い | 長い |
| 入手しやすさ | どこでも買える | ホームセンターによる |

**結論：通常品で十分です。** 観葉植物は1〜2年ごとに植え替えるのが理想なので、粒の寿命と植え替えサイクルが一致します。

硬質赤玉土が向いているのは、植え替え頻度を減らしたい大型鉢や、根をあまりいじりたくない植物に限られます。

## よくある失敗例

### 失敗1：赤玉土100%で植える

赤玉土だけでは保水性が高すぎます。水やり後に土がなかなか乾かず、根腐れの原因になります。必ず排水性を高める素材（パーライト、軽石など）を混ぜてください。

### 失敗2：大粒を主体に使う

「粒が大きい方が水はけが良い」と考えて大粒を主体にすると、根が土に接触できず、水分も養分も吸えなくなります。観葉植物の根は細いため、小粒が適切です。

### 失敗3：古い赤玉土を再利用する

1〜2年使った赤玉土は粒が崩れて微塵になっています。微塵は排水性を大幅に低下させるため、植え替え時は新しい赤玉土を使ってください。

### 失敗4：赤玉土の割合を減らしすぎる

パーライトや軽石を増やしすぎると、今度は保水性が不足します。水やりしてもすぐに乾いてしまい、植物が水分不足になります。赤玉土は最低でも3割は入れてください。

## よくある質問（FAQ）

### Q1. 赤玉土の割合は観葉植物全般で同じですか？

**A.** 基本は5割ですが、植物の特性に合わせて3〜6割の範囲で調整します。サンスベリア・ザミオクルカスなど多肉質の根を持つ植物は4割に抑え、シダ類など湿り気を好む植物は5割を維持したまま保水素材を変えます。

### Q2. 赤玉土を使わずに市販の培養土だけではいけませんか？

**A.** 市販の観葉植物用培養土の多くは赤玉土が主体として配合されています。ただし、ピートモスや腐葉土が多い製品は室内管理で虫・カビが出やすいため、[観葉植物におすすめの土](/soil/recommended-soil-for-houseplants)を参考に選んでください。自分で赤玉土を追加して排水性を高める方法も有効です。

### Q3. 赤玉土と腐葉土の違いは何ですか？

**A.** 赤玉土は無機質（鉱物質）、腐葉土は有機質（植物が分解されたもの）です。赤玉土は土台・排水・通気を担い、腐葉土は栄養・保水・土の柔らかさを担います。役割が違うため、目的に合わせて組み合わせて使います。

### Q4. 赤玉土と日向石はどちらを使えばいいですか？

**A.** 用途が異なります。赤玉土は「保水＋排水のバランス役」、日向石は「排水性の強化役」です。基本配合の主体には赤玉土を使い、排水性を高めたいパキラなど乾燥を好む植物には日向石を追加します。[配合方法の詳細はこちら](/soil/how-to-mix-soil-for-houseplants)

### Q5. 赤玉土はどこで買えますか？コスパの良い入手先は？

**A.** ホームセンター（コーナン・カインズ・コメリなど）が最もコスパが良く、14L前後で500〜800円程度です。少量なら100円ショップでも入手できますが、粒の品質にばらつきがあります。硬質タイプはホームセンターか園芸専門店での購入をおすすめします。

## まとめ

- 観葉植物の赤玉土の割合は**基本5割**
- 赤玉土5割が最適な理由：団粒構造・乾湿サイクル・pH・清潔さの4つ
- 乾燥を好む植物（サンスベリア・ザミオクルカス）は4割に減らし排水材を増やす
- 粒サイズは**小粒が基本**。大型鉢（8号以上）のみ中粒を検討
- 通常の赤玉土で十分。硬質は植え替え頻度を減らしたい場合のみ
- 赤玉土100%はNG。必ずパーライトや軽石と組み合わせる

赤玉土は観葉植物の土の「主役」です。割合さえ正しく決めれば、あとは脇役の素材を調整するだけで、植物に合った理想の土が完成します。
