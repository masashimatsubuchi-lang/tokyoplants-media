# アグラオネマの価格相場｜品種別の選び方

アグラオネマを調べはじめると、同じ「アグラオネマ」という名前で1,000円台のものと6万円を超えるものが並んでいて戸惑います。この差は品質の良し悪しではなく、**系統・サイズ・柄の出方・一点ものかどうか**という4つの要素の掛け算です。この記事では、実際の販売ページで確認できた価格を整理したうえで、自分の予算と環境に合う株の選び方を示します。

<!-- key-facts title="30秒でわかる価格の目安" -->
- **入門**：クラシック系4号で**3,000〜4,000円**前後
- **最安**：ハイドロ用の小苗なら**1,000円以下**もある
- **赤・ピンク系**：4号で**2,000〜5,000円**。柄で大きく変動
- **大型**：8号の株立ちで**10,000円**前後
- **原種ピクタム**：一点もので**15,000〜65,000円**
- **決め手**：サイズより**系統と柄**のほうが価格を動かす
<!-- /key-facts -->

<!-- callout type="info" title="この記事の価格について" -->
本記事の価格は、**2026年10月22日に楽天市場の検索結果で表示されていた出品価格**と、**tokyoplantsオンラインストアに掲載されているアグラオネマ13点の価格**を実際に確認して整理したものです。相場の目安として使えますが、**植物は個体ごとに値付けが異なり、在庫状況で変動します。**購入時は必ず販売ページで最新の価格を確認してください。送料が別途かかる出品も含まれています。
<!-- /callout -->

## 結論

1. <mark>**最初の1株なら、クラシック系（緑・シルバー）の4号で3,000〜4,000円が最も失敗しにくい価格帯。**流通量が多く、耐陰性が高く、環境を選びません。</mark>
2. **赤やピンクのタイカラー系は同じサイズでも価格の幅が広い。**2,000円台で買える品種もあれば、同じ3号で6,000円を超える品種もあります。**差を生むのは柄と流通量**です。
3. **原種のピクタムだけは桁が変わる。**一点ものとして取引され、15,000円から60,000円超まで。買う前に、高湿度を維持できる環境があるかを先に確認してください。

## サイズ（号数）と価格

鉢のサイズは「号」で表され、1号＝直径約3cmです。同じ品種なら、おおむね号数に比例して価格が上がります。

| サイズ | 目安の草丈 | 確認できた価格の例 | 置き場所 |
|---|---|---|---|
| 2〜3寸（ハイドロ苗） | 10cm前後 | 748〜2,139円 | 小さな容器・テラリウム |
| 3号（直径約9cm） | 15〜25cm | 1,980円〜 | デスク・棚 |
| 3.5〜4号（約10〜12cm） | 25〜40cm | 1,780〜4,880円 | 棚・サイドテーブル |
| 5号（約15cm） | 40〜50cm | 3,400円前後 | 床置き・低いスタンド |
| 6号（約18cm） | 50〜60cm | 3,498〜4,380円 | 床置き |
| 8号（約24cm） | 60cm以上 | 9,980円前後 | 床置き・部屋の主役 |

サイズを上げると価格は上がりますが、**管理の難易度も上がります。**鉢が大きいほど土の量が増え、乾くまでの時間が長くなるためです。アグラオネマは過湿に弱い植物なので、「大きいほうがお得」とは一概に言えません。

<!-- character-note character="shadee" type="tip" -->
最初の1鉢は4号くらいがちょうどいいよ。土が乾くまでの時間が読みやすくて、水やりの感覚をつかみやすいサイズ。慣れてから大きい株に進むほうが、結果的に失敗が少ない。
<!-- /character-note -->

## 系統・品種と価格

### クラシック系（緑・シルバー）

| 品種 | 確認できた価格の例 |
|---|---|
| シルバークイーン 4号 | 3,380円／3,680円 |
| シルバークイーン 5号 | 3,400円 |
| シルバークイーン 6号 | 4,380円 |
| シルバークイーン 8号 | 9,980円 |
| マリア 3.5号ポット苗 | 2,980円 |
| マリア 4号（鉢付き） | 3,280〜3,980円 |

**最も価格が安定しているグループ**です。生産量が多く、どの時期でも手に入ります。耐陰性が高いので、室内照明だけの場所にも置けます。はじめての1株、あるいはオフィスや店舗に置く用途であれば、このゾーンから選ぶのが合理的です。

### タイカラー系（赤・ピンク・オレンジ）

| 品種 | 確認できた価格の例 |
|---|---|
| オースピシャスレッド 4号 | 1,780〜2,980円 |
| チャイナレッド 4号 | 3,381円（＋送料） |
| ビューティー | 3,179円 |
| レッドアーミー | 4,279円 |
| アンヤマニー トリカラー | 5,720円 |
| ゴースト 4号 | 4,880円 |
| ウィザードレッド 3号 | 6,600円 |
| 斑入りコンムタツム 3号 | 5,580円 |

幅が大きいのがこのゾーンです。**サイズではなく柄と流通量で値段が決まる**ため、3号でも6,000円を超えることがあります。逆に、流通量の多い赤系であれば4号2,000円前後から手に入ります。

<!-- callout type="warning" title="安い赤系を暗い部屋で買わない" -->
タイカラー系は、光が足りないと新しく出る葉から順に緑へ戻っていきます。すでに出ている葉の色は戻りません。**レースカーテン越しの窓辺を確保できないなら、赤やピンクの品種に投資しても色を維持できない**ということです。その場合はクラシック系のほうが満足度が高くなります。必要な光量の目安は[アグラオネマの発色を良くする方法](/guide/aglaonema-coloring-guide)にPPFDとluxで示しています。
<!-- /callout -->

## 原種ピクタムが一桁高い理由

価格が跳ね上がるのには、はっきりした理由があります。

1. **成長が遅く、短期間で数が揃わない。**量産品のように生産サイクルを回せません
2. **柄が1株ごとに違う。**同じ親から採れた個体でも、濃淡とコントラストが同じものは存在しません
3. **産地のラベルに価値が置かれている。**「アチェ産」「スマトラ」など採取地別に区別され、同じピクタムでも産地ごとに評価が分かれます
4. **選抜と交配が進んでいる。**選抜個体同士を掛け合わせた「F1」は、柄の出方を狙って作られた個体として高値がつきます
5. **栽培難易度が高く、流通過程で歩留まりが悪い。**湿度60〜80%を要求するため、乾燥した環境では状態を落とします

<!-- character-note character="kuro" type="warning" -->
ピクタムを買う前に、湿度を60〜80%で保てるかを先に考えてほしい。加湿器かガラスケースがないと、数万円の株でも葉先から傷んでいく。価格に見合う環境を用意できるかが、買っていいかの判断基準になる。
<!-- /character-note -->

## 買う前のチェックポイント

<!-- steps title="予算と株を合わせる手順" -->
1. **置き場所の明るさを先に決める**：窓辺が取れないならクラシック系。ここで系統が絞られ、価格帯もおおよそ決まる
2. **冬の最低温度を確認する**：どの価格帯の株でも**15℃以上**が前提。確保できないなら春まで待つ
3. **サイズを決める**：初めてなら4号前後。8号の大型株は水やりの難易度が上がる
4. **写真ではなく現物の柄を見る**：一点ものの品種は個体差が大きい。通販なら「現品販売」表記の商品を選ぶ
5. **株元と下葉を確認する**：茎がぐらつく、下葉が落ちて茎だけ伸びている株は前の環境で光が足りていない
6. **送料を含めて比較する**：本体価格が安くても送料が1,000円前後かかる出品がある
<!-- /steps -->

## よくある失敗例

### 安さだけで小苗を買う

ハイドロ用の2寸苗は1,000円以下で手に入りますが、**葉数が少なく、環境の変化に弱い**状態です。いきなり乾燥した冬の室内に置くと、持ち直す前に傷みます。安く始めたい場合でも3〜4号から入るほうが確実です。

### 「希少」の表記を価値の保証と考える

アグラオネマの流通名には統一ルールがなく、「希少」「レア」は販売店の判断で付けられています。**実際に見るべきは柄の出方と株の状態**です。

### 高額なピクタムを環境を整える前に買う

数万円の株でも、湿度が足りなければ葉先から枯れ込みます。**加湿器かガラスケースを先に用意してから**購入してください。

### サイズで選んで水やりに苦労する

8号の大型株は見栄えがしますが、土の量が多く乾きにくい分、冬の過湿リスクが高くなります。管理に慣れてからのほうが安全です。

### 冬に届いて低温でダメージを受ける

配送中の低温は株にとって大きな負担です。**11〜3月の購入では、カイロ同梱などの防寒対応があるかを確認**してください。

## よくある質問

### ホームセンターと専門店で何が違いますか？

ホームセンターはクラシック系の量産品が中心で、価格は安定しています。専門店は品種の選択肢が広く、一点もの扱いの株が多いぶん価格の幅も広くなります。**定番品種なら価格差は小さく、希少な柄を探すなら専門店**という使い分けになります。

### 同じ品種名なのに値段が倍違います

一点もの扱いの品種では普通に起こります。葉の枚数、株の充実度、柄の密度とコントラストで1株ごとに値付けされるためです。

### フリマアプリのほうが安いのでは？

個人出品のほうが安いことはありますが、品種名の正確さ、株の状態、梱包と配送の品質にばらつきがあります。はじめての1株では、状態の説明と写真が充実している販売店を選ぶほうが安全です。

### 値段が高い株ほど育てやすいですか？

**逆です。**高額なピクタム系は湿度60〜80%を要求する上級者向けで、安価なクラシック系のほうが圧倒的に丈夫です。価格と育てやすさは比例しません。

## まとめ

- 価格は**系統・サイズ・柄・一点ものかどうか**の掛け算で決まる
- はじめの1株は**クラシック系の4号、3,000〜4,000円前後**が失敗しにくい
- タイカラー系は同じサイズでも幅が大きい。**柄と流通量**が価格を動かす
- 原種ピクタムは一点もので15,000〜65,000円。**買う前に湿度環境を用意する**
- 価格と育てやすさは比例しない。高い株ほど環境要求が厳しいことが多い
