# 植物好きが見るべき映画・ドキュメンタリー5選｜Amazon Prime対応

植物を育てていると、ふとした瞬間に「この子は何を考えているんだろう」と思うことがある。葉が光に向かって伸びる様子、根が水を探して広がる姿、季節ごとに表情を変える緑——観葉植物と向き合っていると、植物という存在そのものへの興味が自然と深まっていく。

そんな植物好きにこそ、ぜひ観てほしいのが植物・自然・農業をテーマにした映画やドキュメンタリーだ。本やSNSでは得られない「映像の力」は、土の中で起きていること、植物の生存戦略、生態系のつながりを圧倒的なリアリティで体感させてくれる。観た後、自分の鉢植えへの接し方が変わった、土への見方が180度変わったという声は多い。

この記事では、観葉植物好き・植物マニアに特におすすめしたい映画・ドキュメンタリーを5作品セレクトした。Amazon Prime Videoで視聴できるものを中心に、Blu-ray・DVD作品も含めて紹介する。雨の日のインドア時間や、植物の水やりを終えた夜にぜひ。

## 1. ビッグ・リトル・ファーム 理想の暮らしのつくり方（2019年）

**監督: ジョン・チェスター / Amazon Prime Video・Blu-ray対応**

都市生活を捨てた夫婦が荒廃した農地を蘇らせるまでの8年間を追った、感動のドキュメンタリー映画。ロサンゼルスで暮らしていたジョン・チェスターと妻のモリーは、愛犬の鳴き声問題がきっかけでアパートを追い出され、一念発起してカリフォルニア州に200エーカーの農地を購入する。しかしそこは長年放置された痩せた土地——土は固く、栄養はなく、生き物の気配もない。

そこから始まる「土を育てる」という壮大な挑戦が、この映画の核心だ。堆肥をつくり、多様な植物を植え、家畜を導入する。蛆虫が鳥を呼び、鳥が害虫を食べ、糞が土を豊かにする。生態系の循環が少しずつ動き始めるまでの記録は、観ていてただただ美しい。

観葉植物好きへの訴求という意味では「土の重要性」をこれほどわかりやすく伝えてくれる映像作品はないと言っていい。室内の鉢一つにも、土の中の微生物や有機物の循環がある——この映画を観ると、それを実感できる。「最も希望が持てるエコドキュメンタリー」と各国で絶賛された傑作。

**こんな人におすすめ**: 自然に生きることへの憧れがある人 / 土づくりや有機栽培に興味がある人 / 感動系ドキュメンタリーが好きな人

## 2. BBC プライベート・ライフ・オブ・プランツ 植物の世界（1995年）

**ナレーター: デヴィッド・アッテンボロー / DVD BOX**

1995年にBBCが制作した植物ドキュメンタリーの金字塔。当時最先端だったタイムラプス撮影技術を駆使し、植物の成長・繁殖・生存戦略を驚異の映像で記録した6部構成のシリーズだ。ナレーターはイギリスが誇る自然界の語り部、デヴィッド・アッテンボロー。

「植物は動かない」という思い込みを根底から崩してくれる作品だ。種を風に乗せて飛ばすタンポポ、昆虫を引き寄せて捕らえる食虫植物、支柱を求めてゆっくりと巻きつくつる植物——タイムラプスで捉えると、植物は確かに「動いている」。そしてその動きが全て、生きるための精巧な戦略であることに気づかされる。

観葉植物を育てている人が観ると、日々の水やりや置き場所の意味が全く変わってくる。モンステラの葉に穴が開く理由、ポトスが光に向かって葉の向きを変える仕組み——「なぜそうなるのか」の答えが映像で体感できる。30年前の作品ながら今でも色あせない完成度で、植物好きの間では伝説的な一作として語り継がれている。

**こんな人におすすめ**: 植物の仕組みを深く理解したい人 / 知的好奇心が強い人 / BBCドキュメンタリーが好きな人

## 3. ジェレミー・クラークソン 農家になる（Clarkson's Farm）（2021年〜）

**Amazon Original / Prime会員無料**

「最も笑えて、最も心に刺さる農業ドキュメンタリー」として世界中で熱狂的な支持を集めるAmazon Original作品。主人公はイギリスの人気テレビ司会者でクルマ評論家のジェレミー・クラークソン。父親が残したコッツウォルズの農場1000エーカーを引き継いだものの、農業のことは何も知らないという状況からドキュメンタリーは始まる。

驚くべきはその評価だ。IMDb（映画評価サイト）でシーズン1の評価は驚異の9.0。これはBreaking Badや Planet Earthに並ぶ歴史的高評価で、ドキュメンタリー作品としては異例の数字だ。

植物・農業好きへの訴求という点では「土壌改良」「作物の育て方」「天候との闘い」がリアルに描かれており、農業の難しさと面白さを笑いと感動を交えて体感できる。農薬を使わない有機農業への転換を試みる回、大雨で畑が壊滅する回——思い通りにならない自然相手に奮闘するクラークソンの姿は、観葉植物を育てる者としても共感できる部分が多い。「植物を育てることの難しさ」を笑いながら学べる傑作。

**こんな人におすすめ**: ユーモアのある作品が好きな人 / Prime会員でコスパ良く楽しみたい人 / 農業・食に興味がある人

## 4. シード〜生命の糧〜（2016年）

**監督: ジョン・ウェブスター、タゲ・ロジャース / DVD**

衝撃的な事実から始まるドキュメンタリーだ。「20世紀に入ってから、野菜の種の94%が失われた」——商業農業の普及と企業による種の特許化により、数千年かけて人類が守ってきた在来種の多くが消滅の危機に瀕している。その現状を追い、世界中で種の多様性を守ろうとする人々にスポットを当てた作品。

環境活動家のヴァンダナ・シヴァ、霊長類学者のジェーン・グドールら著名人も登場し、種の多様性が失われることの意味を多角的に語る。各地で種を収集・保存する農家たちの活動は、現代のフードシステムへの静かな抵抗でもある。エミー賞にノミネートされた本作は、観た後に植物の「タネ」という存在の価値を根本から考え直させてくれる。

観葉植物好きに刺さるのは「多様性の重要性」というテーマだ。モンステラひとつとっても、デリシオーサ・アダンソニー・タイコンステレーション・アルボと多様な種がある。その多様性を守ることが植物の豊かな未来につながるという視点は、この映画を観ることでより鮮明になる。植物と人間の関係を改めて問い直す一作。

**こんな人におすすめ**: 環境問題・食の安全に関心がある人 / 植物の歴史や文化を深く知りたい人 / ドキュメンタリー映画をじっくり観たい人

## 5. Fantastic Fungi（2019年）

**監督: ルイス・シュワルツバーグ / Netflix等で配信中**

菌類の世界を扱いながら、最終的に「植物と土と菌類の関係」という観葉植物好きが最も知るべきテーマに辿り着く奇跡のドキュメンタリーだ。菌糸ネットワーク（マイコリザ）が森全体で植物と栄養をやり取りしていること、木々が菌類を介してコミュニケーションを取っていること——その驚異の事実を、息をのむような美麗な映像で体感させてくれる。

観葉植物の土の中にも、目には見えない菌糸ネットワークが存在する。植物の根と菌類（菌根菌）が共生することで、リンや水分の吸収効率が劇的に上がる——Fantastic Fungiを観ると、そうした「見えない世界」への理解が一気に深まる。良い土を使う意味、安易に殺菌剤を使ってはいけない理由が、理屈ではなく映像の体験として刻まれる。

マイケル・ポーランをはじめとする著名な生物学者・思想家たちのインタビューも充実しており、科学的な情報量も豊富だ。Netflix・Apple TV+等の各種サービスで視聴できるため、加入しているサービスで探してみてほしい。植物好きの友人に「今すぐ観て」と言いたくなる一本。

**こんな人におすすめ**: 土の中の世界に興味がある人 / 科学的な視点で植物を理解したい人 / 視覚的に美しい映像作品が好きな人

## まとめ

植物の映画やドキュメンタリーを観ることは、単なる娯楽以上の体験をもたらす。土が持つ力、植物が生きるための戦略、生態系の精巧なつながり——それらを映像で体感すると、毎日の水やりや植え替えの意味が全く変わってくる。

今回紹介した5作品はそれぞれ異なるアプローチで「植物・自然・土」の世界を描いているが、共通するメッセージがある。それは「植物は私たちが思っている以上に、複雑で、賢く、つながっている」ということだ。

| 作品 | テーマ | 視聴方法 |
|------|--------|----------|
| ビッグ・リトル・ファーム | 土づくり・農場再生 | Amazon Prime / Blu-ray |
| プライベート・ライフ・オブ・プランツ | 植物の生存戦略 | DVD |
| クラークソン農家になる | 農業・土壌・育て方 | Amazon Prime（無料） |
| シード〜生命の糧〜 | 種の多様性・食の未来 | DVD |
| Fantastic Fungi | 菌類・菌根菌・土の生態系 | Netflix等 |

観葉植物への愛着は、育てるだけでなく「知ること」でも深まる。雨の日の休日、植物の隣でソファに座りながら、これらの作品をぜひ観てみてほしい。きっとその後、植物の葉の一枚一枚が、少し違って見えてくるはずだ。
